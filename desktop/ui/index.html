01 / 03

      
How Alias protects your data

      
    
        
  1. Your tool sends its request to Alias instead of Mistral.
    2. 
        
  2. Alias finds the personal data: names, addresses, IBANs, e-mails, phone
          numbers… Each value becomes an alias such as [PERSON_1].
    3. 
        
  3. Mistral answers with the aliases. It never receives the values Alias
          found.
    4. 
        
  4. Alias puts the real values back and returns the answer to your tool.
    5. 
      

      
What the detector misses reaches Mistral as it is: stay careful with very
        sensitive documents.

      

        
      

    


    

      
02 / 03

      
Add your Mistral key

      
Alias calls Mistral with your own API key, so what you use is billed to your
        Mistral account.

      
    
        
  1. Open console.mistral.ai and sign in.
    2. 
        
  2. Go to API keys and create a key.
    3. 
        
  3. Copy it and paste it here.
    4. 
      

      

        
        
      

      

      
Alias checks the key with Mistral, then keeps it in the macOS keychain. It is
        never shown again, and your tools never need it.

      

        
      

    


    

      
03 / 03

      
Connect your tools

      
In each tool that uses Mistral (a script, LibreChat, n8n…), change two
        settings.

      

        
Base URL instead of https://api.mistral.ai/v1

        

          http://127.0.0.1:8001/v1
          
        

        
API key instead of your Mistral key

        

          …
          
        

      

      

        Example in Python
        
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8001/v1",
    api_key="<the API key above>",
)
answer = client.chat.completions.create(
    model="mistral-small-latest",
    messages=[{"role": "user", "content": "Summarize this letter: …"}],
)
print(answer.choices[0].message.content)

      

      
Keep Alias open while you use your tools: they reach Mistral through it.

Alias

Mask the personal data in a French or English text before it goes to an LLM. The detector runs in this browser: the text never leaves the page.

First visit: the model (about 600 MB) downloads into your browser, which takes about 5 minutes on a typical connection. It is kept for the next visits, which start at once.

Put the values back (in this browser)

Send the masked text to the LLM you use (Le Chat, ChatGPT…) with your request, for instance "Summarise this document", then paste its answer here: the aliases become the real values again, without the values ever leaving this page.

Alias, open source (MIT): code, results and limits. Model: mmBERT-small fine-tuned, plus checksum and keyword rules. No detector is perfect: read the masked text before sending it.
